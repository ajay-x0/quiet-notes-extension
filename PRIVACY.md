# Quiet Notes privacy information

Applies to version 1.0.0, September 26, 2026.

Quiet Notes stores titles, note text, identifiers, created/updated timestamps, and Trash
status locally using Chrome extension storage. It does not transmit notes to the
developer or any server. It has no analytics, advertisements, accounts, tracking,
website-reading permissions, or cloud synchronization.

The storage permission is used to retain your notes after the popup closes. JSON export
creates a plain-text backup in your downloads. Anyone with access to that backup can
read it; share and store it accordingly. Import reads only the file you explicitly choose.

Deleted notes remain in local Trash until you choose Delete forever. Uninstalling the
extension removes its Chrome-managed local storage, but does not delete exported backup
files. This extension does not encrypt notes itself.

Before a public store release, the publisher should host this information on a publicly
accessible page and add their real support contact. No public publisher contact has been
configured in this local build.
